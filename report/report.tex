\begin{abstract}
This report presents a Multi-Agent Reinforcement Learning framework for a two-dimensional America's Cup regatta simulator. The project extends a didactic sailing reinforcement-learning setting into a competitive PettingZoo ParallelEnv in which two autonomous boats learn continuous rudder and sail-trim control under stochastic wind, polar-performance constraints, and hybrid displacement/foiling dynamics. The agents are trained with Proximal Policy Optimization (PPO) through Stable-Baselines3 and SuperSuit vectorization. The available evidence consists of the trained model artifact, rendered trajectories, and exported training plots for mean episodic reward and mean Velocity Made Good (VMG). Since raw evaluation logs are not present in the repository, this report does not claim a measured finish rate; instead, it provides a code-grounded formulation of the environment and a qualitative analysis of the observed learning behavior.
\end{abstract}

\section{Introduction}
Autonomous sailing is a sequential decision-making problem in which control, navigation, and environmental adaptation are tightly coupled. A sailboat cannot move directly in arbitrary directions: its feasible velocity is constrained by the wind angle, the aerodynamic efficiency of the sails, hydrodynamic drag, and, in modern high-performance boats, the transition between displacement sailing and foiling. America's Cup racing adds a further competitive layer: each boat must not only optimize its own progress around the course, but also react to an opponent while respecting tactical constraints and racing rules.

This project, \textit{CoppaAmerica Multiagent}, implements a simplified but technically rich 2D simulator of an America's Cup match race. The environment contains two agents, \texttt{red\_boat} and \texttt{blue\_boat}, a rectangular race field, an upwind/downwind course with mandatory gates, a stochastic wind field, continuous rudder and sail-trim actions, and a dense reward function designed to encourage progress, VMG, trim efficiency, foiling stability, and safe tactical interactions.

The work is conceptually connected to the course notebook \textit{RL basics: learning how to sail}, where a single sailboat learns to reach a waypoint in a simplified Gymnasium environment using basic state variables, actions, rewards, polar behavior, and VMG. The present project generalizes that educational setting along four dimensions: it moves from a single-agent task to a competitive multi-agent environment, from simplified/discrete steering to continuous control, from a basic physical model to a hybrid displacement/foiling polar model, and from a fixed or simple wind model to stochastic spatio-temporal wind dynamics.

\section{Background}

\subsection{Notation and Agent--Environment Interaction}
Following the notation used in the course notes, random variables are denoted by uppercase letters, such as $S_t$, $A_t$, and $R_t$, while their realizations are denoted by lowercase letters, such as $s_t$, $a_t$, and $r_t$. Expectations are taken with respect to the probability distribution induced jointly by the policy and the environment dynamics.

In Reinforcement Learning, an agent interacts with an environment over discrete time steps. At time $t$, the agent observes a state $S_t$, selects an action $A_t$, receives a reward $R_t$, and the environment transitions to a new state $S_{t+1}$. The interaction can be written as
\begin{equation}
    S_t \xrightarrow{A_t} (S_{t+1}, R_t).
\end{equation}
In stochastic environments, the next state and reward are not deterministic functions of the current state and action. They are sampled from environment-induced distributions:
\begin{equation}
    S_{t+1} \sim P(\cdot \mid S_t, A_t),
    \qquad
    R_t \sim R(\cdot \mid S_t, A_t).
\end{equation}

\subsection{Markov Decision Processes}
The Markov property states that the future depends on the present state and not on the full history:
\begin{equation}
    \Pr(X_{t+1}=j \mid X_t=i, X_{t-1}, \ldots, X_0)
    =
    \Pr(X_{t+1}=j \mid X_t=i).
\end{equation}
An MDP formalizes a sequential decision problem as a tuple
\begin{equation}
    M = (\mathcal{S}, \mathcal{A}, P, r, \mu, \gamma),
\end{equation}
where $\mathcal{S}$ is the state space, $\mathcal{A}$ is the action space, $P(s' \mid s,a)$ is the transition probability, $r(s,a)$ is the reward function, $\mu$ is the initial state distribution, and $\gamma \in [0,1]$ is the discount factor.

In the present simulator, each boat observes only a feature vector derived from the full simulator state. The implementation is therefore best interpreted as a multi-agent, partially observed control problem, but the learning interface follows the standard MDP formulation at the level of each agent's observation and action.

\subsection{Policies, Trajectories, and Return}
A policy defines how actions are selected from states. A deterministic policy has the form
\begin{equation}
    A_t = \pi(S_t),
\end{equation}
whereas a stochastic policy samples an action according to a conditional distribution:
\begin{equation}
    A_t \sim \pi(\cdot \mid S_t).
\end{equation}
For a finite horizon $T$, a trajectory can be written as
\begin{equation}
    \tau = (s_0,a_0,s_1,a_1,\ldots,s_T,a_T).
\end{equation}
Under a stochastic policy $\pi$, the probability of such a trajectory is
\begin{equation}
    p(\tau) = p(s_0)\prod_{t=0}^{T}\pi(a_t \mid s_t)P(s_{t+1}\mid s_t,a_t).
\end{equation}

The objective of reinforcement learning is not to maximize immediate reward alone, but cumulative future reward. The discounted return from time $t$ is
\begin{equation}
    G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \gamma^3 R_{t+3} + \cdots
    = \sum_{k=0}^{\infty}\gamma^k R_{t+k}.
\end{equation}
The goal is to find a policy that maximizes the expected discounted return:
\begin{equation}
    J(\pi) =
    \mathbb{E}_{s_0 \sim \mu,\pi}
    \left[
        \sum_{t=0}^{\infty}\gamma^t R(S_t,A_t)
    \right].
\end{equation}

\subsection{Value Functions and Bellman Equation}
The state-value function measures how much return is expected when starting from state $s$ and following policy $\pi$:
\begin{equation}
    V^\pi(s) =
    \mathbb{E}_{\pi}
    \left[
        \sum_{t=0}^{\infty}\gamma^t R_t
        \mid S_0=s
    \right].
\end{equation}
The action-value function measures the expected return when first taking action $a$ in state $s$ and then following policy $\pi$:
\begin{equation}
    Q^\pi(s,a) =
    \mathbb{E}_{\pi}
    \left[
        \sum_{t=0}^{\infty}\gamma^t R_t
        \mid S_0=s, A_0=a
    \right].
\end{equation}
The two functions are related by averaging action values under the policy:
\begin{equation}
    V^\pi(s) = \sum_{a}\pi(a\mid s)Q^\pi(s,a).
\end{equation}
The Bellman expectation equation expresses the recursive structure of value:
\begin{equation}
    V^\pi(s) =
    \sum_a \pi(a\mid s)
    \left[
        r(s,a) + \gamma \sum_{s'}P(s'\mid s,a)V^\pi(s')
    \right].
\end{equation}
Equivalently, the action-value function satisfies
\begin{equation}
    Q^\pi(s,a) =
    r(s,a) + \gamma \sum_{s'}P(s'\mid s,a)V^\pi(s').
\end{equation}

\subsection{Model-Free Learning, Function Approximation, and PPO}
In model-free reinforcement learning, the transition model $P$ and reward model $r$ are not assumed to be known analytically. Instead, the agent learns from sampled transitions $(S_t,A_t,R_t,S_{t+1})$. With function approximation, value functions or policies are represented by parameterized models, typically neural networks. The temporal-difference error for a value approximation $V_\theta$ is
\begin{equation}
    \delta_t = R_t + \gamma V_\theta(S_{t+1}) - V_\theta(S_t),
\end{equation}
and the corresponding squared loss is
\begin{equation}
    L(\theta)=
    \frac{1}{2}
    \left(R_t + \gamma V_\theta(S_{t+1}) - V_\theta(S_t)\right)^2.
\end{equation}

The America's Cup simulator has continuous observations, continuous actions, and non-linear transition dynamics induced by wind, polar curves, foiling state, and multi-agent interaction. For this reason, the implementation uses Proximal Policy Optimization (PPO), as provided by Stable-Baselines3, as a practical model-free policy-gradient method suitable for continuous control. PPO is not used here to introduce additional theoretical machinery beyond the course notes; rather, it is the concrete algorithmic tool that maps the function-approximation perspective to a trainable continuous-control policy.

\section{Methodology}

\subsection{Race Course and Multi-Agent Formulation}
The environment is implemented as a PettingZoo \texttt{ParallelEnv} with two agents:
\begin{equation}
    \mathcal{I}=\{\texttt{red\_boat},\texttt{blue\_boat}\}.
\end{equation}
The field has width $W=1900$ m and length $L=4100$ m. The top gate is located at $y=3900$ m, the bottom gate at $y=200$ m, and the gate width is $300$ m. Each episode has a maximum duration of $1800$ simulation steps with $\Delta t=1$ s.

The race is decomposed into sequential legs. The boats start below the bottom gate, cross the start gate, sail upwind toward the top gate, perform a rounding maneuver, and then sail downwind toward the bottom gate. Gate violations, course violations, collisions, and excessive spinning can terminate the episode with severe penalties.

\subsection{Observation Space}
Each agent receives a normalized continuous observation vector
\begin{equation}
    o_t^i \in [-1,1]^{23}.
\end{equation}
The vector contains normalized position, speed, heading, relative wind angle, local wind speed, distances and bearings to the active gate marks, current rudder and trim state, foiling state, active foil side, leg indicator, and opponent-relative features. With frame stacking configured as $4$, the effective policy input is
\begin{equation}
    \tilde{o}_t^i =
    (o_{t-3}^i,o_{t-2}^i,o_{t-1}^i,o_t^i)
    \in [-1,1]^{92}.
\end{equation}

\subsection{Action Space and Kinematics}
The action space is two-dimensional and continuous:
\begin{equation}
    a_t^i=(u_t^i,z_t^i)\in[-1,1]^2,
\end{equation}
where $u_t^i$ is the rudder command and $z_t^i$ is the sail-trim command. The trim action is mapped to a physical trim level by
\begin{equation}
    \tau_t = \mathrm{clip}\left(\frac{z_t+1}{2},0,1\right).
\end{equation}
The heading evolves according to a speed-dependent turn rate. Let $v_t$ be the current speed in knots, $v_{\max}=50$, $\rho_{\min}=0.12$, and $\omega_{\max}=25^\circ$. The effective turn factor is
\begin{equation}
    \rho_t = \rho_{\min}+(1-\rho_{\min})\frac{v_t}{v_{\max}},
\end{equation}
and the heading update is
\begin{equation}
    \psi_{t+1} =
    \left(\psi_t + u_t \rho_t \omega_{\max}\Delta t\right)\bmod 2\pi.
\end{equation}
The boat position is updated using the simulated speed converted from knots to meters per second:
\begin{equation}
    p_{t+1} =
    p_t +
    0.514\,v_{t+1}\Delta t
    \begin{bmatrix}
        \cos \psi_{t+1}\\
        \sin \psi_{t+1}
    \end{bmatrix}.
\end{equation}

\subsection{Stochastic Wind Field}
The wind model contains a global base wind and a spatial perturbation grid. At reset, the base wind direction is initialized near north-to-south flow, with random angular offset, and the base wind speed is sampled from $[15,22]$ knots. At each step,
\begin{align}
    \Theta_{t+1} &=
    (\Theta_t+\varepsilon^\Theta_t)\bmod 2\pi,
    &
    \varepsilon^\Theta_t &\sim \mathcal{U}(-0.02,0.02),\\
    U_{t+1} &=
    \mathrm{clip}(U_t+\varepsilon^U_t,15,22),
    &
    \varepsilon^U_t &\sim \mathcal{U}(-0.3,0.3).
\end{align}
Local gusts are represented by a $10\times 10$ grid. For each cell $(m,n)$, direction and speed perturbations evolve as
\begin{align}
    D_{t+1}^{m,n}
    &=
    \mathrm{clip}\left(
        0.95D_t^{m,n}+\eta^{D,m,n}_t,
        -2.5(0.15),2.5(0.15)
    \right),\\
    S_{t+1}^{m,n}
    &=
    \mathrm{clip}\left(
        0.95S_t^{m,n}+\eta^{S,m,n}_t,
        -2.5(2.0),2.5(2.0)
    \right),
\end{align}
where $\eta^{D,m,n}_t\sim\mathcal{N}(0,0.015^2)$ and $\eta^{S,m,n}_t\sim\mathcal{N}(0,0.2^2)$. The local wind experienced by the boat is obtained by bilinear interpolation of the four nearest grid cells and then added to the base wind.

\subsection{Polar-Speed Model and Foiling Dynamics}
The code computes a relative wind angle $\phi_t\in[0,180]$ degrees from the local wind direction and boat heading. The theoretical polar speed is
\begin{equation}
    v^{\mathrm{base}}_t =
    \min(q_{\kappa_t}(\phi_t)U^{\mathrm{local}}_t,50),
\end{equation}
where $\kappa_t \in \{D,F\}$ denotes displacement or foiling mode. In foiling mode, the multiplier is
\begin{equation}
q_F(\phi)=
\begin{cases}
0, & 0\le \phi <45,\\
1.0+0.15(\phi-45), & 45\le \phi <55,\\
2.5+0.024(\phi-55), & 55\le \phi <100,\\
3.6+0.015(\phi-100), & 100\le \phi <140,\\
4.2-0.03(\phi-140), & 140\le \phi <170,\\
3.3-0.25(\phi-170), & 170\le \phi \le 180.
\end{cases}
\end{equation}
In displacement mode, the multiplier is
\begin{equation}
q_D(\phi)=
\begin{cases}
0, & 0\le \phi <35,\\
0.3+0.03(\phi-35), & 35\le \phi <50,\\
0.75+0.015(\phi-50), & 50\le \phi <110,\\
1.65-0.01(\phi-110), & 110\le \phi <140,\\
1.35-0.005(\phi-140), & 140\le \phi \le 180.
\end{cases}
\end{equation}

The optimal trim $\tau^\star(\phi,\kappa)$ is computed by linear interpolation over mode-specific trim points. The trim efficiency is Gaussian:
\begin{equation}
    e_\tau =
    \exp\left[
        -\frac{1}{2}
        \left(
            \frac{|\tau-\tau^\star|}{\sigma_\kappa}
        \right)^2
    \right],
    \qquad
    \sigma_F=0.12,\quad \sigma_D=0.16.
\end{equation}
The speed multiplier induced by trim is
\begin{equation}
m_\tau(e_\tau,\kappa)=
\begin{cases}
0.60+0.65e_\tau, & \kappa=F,\\
0.72+0.42e_\tau, & \kappa=D.
\end{cases}
\end{equation}
The target speed is
\begin{equation}
    v^{\mathrm{target}}_t =
    \min(v^{\mathrm{base}}_t m_\tau(e_\tau,\kappa_t),50).
\end{equation}
Actual speed follows an inertia update:
\begin{equation}
    v_{t+1} =
    I_{\kappa_t}v_t + (1-I_{\kappa_t})v^{\mathrm{target}}_t,
    \qquad
    I_F=0.98,\quad I_D=0.85.
\end{equation}
The boat enters foiling mode when $v_{t+1}\ge 18$ knots and drops out of foiling when $v_{t+1}<15$ knots.

\subsection{Reward Shaping}
The reward is dense and multi-objective. Let $g_t$ be the active target, $p_t$ the boat position, and
\begin{equation}
    d_t = \|p_t-g_t\|_2,\qquad
    \Delta d_t=d_{t-1}-d_t.
\end{equation}
The progress reward is asymmetric: losing distance is penalized more strongly than gaining distance is rewarded. With $c_t=1.8$ in foiling mode and $c_t=0.65$ otherwise,
\begin{equation}
r^{\mathrm{prog}}_t=
\begin{cases}
c_t\Delta d_t, & \Delta d_t\ge 0,\\
1.8c_t\Delta d_t, & \Delta d_t<0.
\end{cases}
\end{equation}
VMG is the projection of boat velocity onto the direction of the active target:
\begin{equation}
    \mathrm{VMG}_t =
    v_t
    \begin{bmatrix}
        \cos \psi_t\\
        \sin \psi_t
    \end{bmatrix}^{\top}
    \frac{g_t-p_t}{\|g_t-p_t\|_2},
    \qquad
    \widehat{\mathrm{VMG}}_t =
    \mathrm{clip}\left(\frac{\mathrm{VMG}_t}{50},-1,1\right).
\end{equation}
With $\lambda_t=1.6$ on the upwind leg and $\lambda_t=1.25$ otherwise, the VMG term is
\begin{equation}
    r^{\mathrm{vmg}}_t =
    8.5\lambda_t\max(\widehat{\mathrm{VMG}}_t,0)
    +4.0\lambda_t\min(\widehat{\mathrm{VMG}}_t,0).
\end{equation}

Let $\beta_t$ be the bearing from the boat to the target and
\begin{equation}
    h_t = \frac{|\mathrm{wrap}(\beta_t-\psi_t)|}{\pi}.
\end{equation}
The heading-alignment term is
\begin{equation}
    r^{\mathrm{head}}_t =
    1.2(1-h_t)-3.0\max(h_t-0.75,0).
\end{equation}
The rudder penalty discourages aggressive and oscillatory steering:
\begin{equation}
    r^{\mathrm{rudder}}_t =
    -2|u_t|^3 -5(u_t-u_{t-1})^2.
\end{equation}

Trim and foiling rewards are
\begin{align}
    r^{\mathrm{trim}}_t
    &=
    8.5(e_{\tau,t}-0.72)
    -5.5|\tau_t-\tau_{t-1}|^{1.5}
    -18\max(|\tau_t-\tau_t^\star|-\xi_t,0)\mathbb{I}[v_t>10],\\
    r^{\mathrm{vmg\mbox{-}trim}}_t
    &=
    5\max(\widehat{\mathrm{VMG}}_t,0)(e_{\tau,t}-0.50),
\end{align}
where $\xi_t=0.18$ on the upwind leg and $\xi_t=0.24$ otherwise. If a boat drops from foiling to displacement mode, it receives
\begin{equation}
    r^{\mathrm{drop}}_t=-40.
\end{equation}
The remaining speed and foiling terms are
\begin{equation}
r^{\mathrm{foil}}_t =
\begin{cases}
1.1(v_t-15), & \kappa_t=F,\\
-1.5, & \kappa_t=D,
\end{cases}
\qquad
r^{\mathrm{low}}_t = -3\mathbb{I}[v_t<15],
\end{equation}
and
\begin{equation}
    r^{\mathrm{speed}}_t =
    -0.35\max(v^{\mathrm{leg}}-v_t,0)
    +0.28v_t\mathbb{I}[\Delta d_t>0],
\end{equation}
where $v^{\mathrm{leg}}=20$ knots on the upwind leg and $24$ knots otherwise.

The multi-agent tactical advantage compares the two boats' distances to their active targets:
\begin{equation}
    r^{\mathrm{tac}}_t =
    1.5\,\mathrm{clip}
    \left(
        \frac{d^{\mathrm{opp}}_t-d_t}{\sqrt{W^2+L^2}},
        -1,1
    \right).
\end{equation}
The course-direction shaping term rewards movement along the appropriate vertical direction:
\begin{equation}
r^{y}_t=
\begin{cases}
0.15(y_t-y_{t-1}), & \ell_t\in\{0,1\},\\
-0.15(y_t-y_{t-1}), & \ell_t\notin\{0,1\}.
\end{cases}
\end{equation}

Collision avoidance is implemented through near-collision, time-to-collision, and hard-collision penalties. If $d^{ij}_t$ is the distance between two boats and $d^{ij}_t<40$, the near-collision penalty is
\begin{equation}
    p^{\mathrm{near}}_t =
    3\frac{40-d^{ij}_t}{40}.
\end{equation}
If the closing speed $c^{ij}_t$ is positive, the time-to-collision is
\begin{equation}
    \mathrm{TTC}_t = \frac{d^{ij}_t}{c^{ij}_t}.
\end{equation}
For $\mathrm{TTC}_t<4$, the predictive penalty is
\begin{equation}
    p^{\mathrm{ttc}}_t =
    5\left(1-\frac{\mathrm{TTC}_t}{4}\right)
    \frac{40-d^{ij}_t}{40}.
\end{equation}
If $d^{ij}_t<20$, the overlap penalty is
\begin{equation}
    p^{\mathrm{coll}}_t =
    20\frac{20-d^{ij}_t}{20},
\end{equation}
with a multiplier $1.6$ applied to the port-tack boat on opposite tacks. Hard violations such as severe collision, missed gates, out-of-bounds movement, wrong-course movement, failed rounding, and spin violation receive a terminal penalty of $-10000$.

Gate bonuses are sparse but important:
\begin{equation}
    b_t =
    400\,\mathbb{I}[\text{valid start gate}]
    +500\,\mathbb{I}[\text{valid top rounding}]
    +B^{\mathrm{finish}}_t,
\end{equation}
where
\begin{equation}
B^{\mathrm{finish}}_t=
\begin{cases}
2500+1000\frac{1800-t}{1800}, & \text{first finisher},\\
700, & \text{second finisher},\\
0, & \text{otherwise}.
\end{cases}
\end{equation}
Combining the dense components, gate events, and terminal events, the step reward is
\begin{align}
r_t ={}&
r^{\mathrm{prog}}_t
 + r^{\mathrm{vmg}}_t
 + r^{\mathrm{head}}_t
 + r^{\mathrm{rudder}}_t
 + r^{\mathrm{trim}}_t
 + r^{\mathrm{vmg\mbox{-}trim}}_t
 + r^{\mathrm{foil}}_t
 + r^{\mathrm{low}}_t
 + r^{\mathrm{speed}}_t \nonumber\\
{}&
 + r^{\mathrm{tac}}_t
 + r^{y}_t
 -0.25
 - p^{\mathrm{near}}_t
 - p^{\mathrm{ttc}}_t
 - p^{\mathrm{coll}}_t
 + b_t
 + p^{\mathrm{terminal}}_t.
\end{align}

\subsection{Comparison with the Course Notebook}
The class notebook introduces a didactic sailing task with a single agent, a simplified state representation, basic actions, reward based on target distance and speed, and a simplified polar/VMG model. The present project preserves the same conceptual core--learning a sailing policy from interaction--but substantially increases the complexity of the environment. It introduces two simultaneous agents, opponent-relative observations, PettingZoo parallel execution, continuous rudder and sail-trim actions, stochastic wind, gate logic, collision handling, Rule 10-inspired penalties, and a hybrid displacement/foiling performance model.

This progression is important pedagogically: the project remains grounded in the course's MDP and model-free RL formulation, but demonstrates how the same concepts scale to a richer multi-agent control problem.

\section{Conclusions}
This report formalized the \textit{CoppaAmerica Multiagent} simulator as a model-free reinforcement-learning problem with continuous observations, continuous actions, stochastic wind, hybrid boat dynamics, and multi-agent tactical interaction. The theoretical background follows the course progression from agent-environment interaction to MDPs, policies, return, value functions, Bellman equations, model-free learning, and function approximation. PPO is then used as the practical continuous-control algorithm.

The main strength of the project is the integration of several interacting mechanisms: polar performance, trim efficiency, foiling transitions, VMG optimization, tactical advantage, gate sequencing, and collision/rule penalties. The main limitation of the current report is empirical: the repository does not contain raw evaluation logs, so finish rates and DNF distributions cannot be stated rigorously. Future work should add a deterministic evaluation script that runs a fixed set of seeds, records terminal reasons, computes finish rates and DNF categories, and exports a reproducible CSV table for inclusion in the report.
